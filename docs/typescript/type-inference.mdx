# 타입 추론 및 타입 검사 메커니즘 (Type Inference)

타입스크립트(TypeScript)는 명시적으로 타입을 기재하지 않더라도 코드의 맥락(Context)을 분석하여 변수와 함수의 타입을 자동으로 추론(Inference)하는 정적 타입 시스템을 가지고 있다.

타입 추론과 타입 검사기(Type Checker)의 동작 원리를 정리한다.

---

## 1. 타입 검사 (Type Checking)

타입 검사는 컴파일 타임에 코드의 심벌(Symbol)에 대한 대입, 참조, 연산이 올바른지 확인하는 과정이다.

- **타입 환경 (Type Environment)**: 특정 스코프 내에서 변수명이 어떤 타입에 매핑되어 있는지 추적.
- **서브타이핑 (Subtyping)**: `A` 타입이 `B` 타입의 모든 구조적 조건을 충족하면 `A`를 `B`의 서브타입으로 간주 (구조적 타이핑 - Structural Typing).

---

## 2. 타입 추론 (Type Inference) 동작 원리

### 1) 기본 값 할당에 의한 추론
변수를 선언하고 초기값을 할당하면 해당 값의 타입으로 자동 할당된다.

```typescript
let num = 10; // number 타입으로 추론
let str = "hello"; // string 타입으로 추론

// const 선언 시 리터럴 타입(Literal Type)으로 추론 (Narrowing)
const constStr = "hello"; // "hello" 리터럴 타입
```

### 2) 문맥상 타입 추론 (Contextual Typing)
함수 콜백이나 이벤트 핸들러 위치에 따라 타입스크립트가 인자의 타입을 역으로 추론한다.

```typescript
window.onmousedown = function (mouseEvent) {
  // mouseEvent는 MouseEvent 타입으로 자동으로 문맥상 추론됨
  console.log(mouseEvent.button);
};
```

---

## 3. 제네릭과 제약조건 (`extends`)

제네릭은 타입 인자(Type Parameter) 간의 관계를 표현하는 함수와 같다. `extends` 키워드를 사용하여 허용할 상위 타입을 제약할 수 있다.

```typescript
// T는 length 속성을 가진 객체 형태이어야 함을 제약
function getLength<T extends { length: number }>(item: T): number {
  return item.length;
}

getLength("hello"); // OK (string은 length 소유)
getLength([1, 2, 3]); // OK (Array는 length 소유)
// getLength(123); // Error: number는 length 속성이 없음
```
