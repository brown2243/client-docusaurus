# NextJS에 대해

- **The React Framework for the Web**
- React는 UI용 라이브러리, **Next.js는 서버 기능을 포함한 프레임워크**
- 아에 서버처럼 사용한다기 보다는, 서버가 해줄 수 있는 클라이언트 최적화를 해준다.

## 다양한 렌더링 전략

### SSR (Server-Side Rendering)

- 사용자가 페이지를 요청(Request)할 때마다 서버에서 HTML을 생성
- 기본적으로 fetch에서 cache: 'no-store' 옵션을 쓰거나 동적 함수(쿠키 등)를 쓰면 SSR로 동작

### SSG (Static Site Generation)

- 빌드 시점에 미리 모든 페이지의 HTML을 생성
- 별다른 설정이 없으면 SSG로 동작

### ISR (Incremental Static Regeneration)

- SSG로 빌드해두고, 정해진 시간마다 서버가 데이터를 다시 가져와서 페이지를 새로 생성

### CSR (Client-Side Rendering)

- 서버는 뼈대만 보내고, 클라이언트에서 JS로 다 그림
- "use client"

## 파일 기반 라우팅 (File-based Routing)

- react-router-dom 같은 라이브러리가 필요 없음
- 그냥 디렉터리 구조가 URL

## 최적화

### 이미지 최적화

- 기존의 `<img>`는

  - 1. 화면 덜컥임 (CLS): 이미지가 로드되기 전엔 공간을 안 잡고 있다가, 로드되면 레이아웃 변경시킴
  - 2. 3MB짜리 원본 이미지를 모바일에서도 불러옴
  - 3. 브라우저가 지원하는 이미지만 사용가능
  - 4. viewport 밖에 있는 이미지까지 전부 로드

- next/image는 이 모든 문제를 자동으로 해결

#### 화면 덜컥임

- next/image는 width와 height 속성을 (대부분) 필수
- 이 정보를 바탕으로 빈 박스(placeholder)를 만들어 공간을 확보
- 나중에 이미지가 로드되어도 레이아웃이 밀리지 않음

#### 원본 이미지 로드

- 3MB짜리 원본 이미지(my-image.jpg)를 자동 리사이징 및 srcset 생성
- 사용자가 모바일로 접속하면, Next.js 서버(또는 CDN)가 이걸 실시간으로 360px 너비의 리사이징된 이미지 전송
- 브라우저는 srcset을 보고 자기 화면 크기에 가장 적합한 이미지를 스스로 선택

#### 최신 포맷 자동 변환 (WebP, AVIF)

- 이미지 하나로 사용자가 어떤 브라우저를 사용하는지 체크해서 가장 용량 작은 포맷으로 전송해주기를 처리해주는 것
- 사용자의 브라우저가 WebP나 AVIF를 지원하는지 Next.js가 자동으로 감지
- 사용자 브라우저가 지원하면 첫 요청 시점에 변환해서 전송
- 둘 다 지원 안 하면 원본 jpg
- 이 기능은 요청시점에 서버가 동작하고 있어야 해서 SSG 방식에는 동작하지 않음

#### Lazy Loading 기본 탑재

- 이미지가 보일 때쯤 로드가
- 페이지의 핵심 이미지(LCP, Largest Contentful Paint)라면, 예를 들어 메인 썸네일이라면, 빨리 로드해야 하니 priority={true} 속성 사용

### 폰트 최적화

- 웹폰트를 그냥 `<link>` 태그로 구글 폰트에서 불러오면

  - 외부 네트워크 요청: 내 사이트 로드와 별개로, fonts.google.com에 요청을 보내고 폰트 파일을 받아와 함(FCP 지연)
  - FOUT / FOIT: 폰트가 로드되기 전까지 글자가 안 보이거나(FOIT), 기본 폰트(굴림체...)로 보이다가(FOUT) 폰트가 로드되면 변경
  - 폰트에 따라 글자 폭이 달라져서 사이트 전체 레이아웃이 다시 변경

- **next/font는 위 문제들을 빌드 타임에 해결**

#### 네트워크 요청 제로

- 빌드 시점에, Next.js가 폰트 파일을 다운로드해서 폰트 파일을 직접 서빙

#### 레이아웃 시프트(CLS) 제어

- 빌드 시점에 Roboto 폰트의 크기, 자간 등 모든 메트릭(metric) 정보를 미리 계산
- Fallback Font가 Roboto와 **동일한 공간**을 차지하도록 만드는 CSS를 자동으로 생성

#### 자동 서브셋팅 (Subsetting)

- 폰트 파일은 용량이 큼.
- next/font는 빌드 시점에 폰트 파일에서 해당 언어에 필요한 글자만 추출한 '서브셋' 폰트 파일을 생성
